# 月面回响 · Lunar Relay

原创像素科幻生存动作游戏。武器自动开火，玩家靠走位和冲刺躲避敌群，拾取能源并升级模块。战役从沙漠基地开始，逐关解锁雨林深处、寒冻南极、太空电梯、保卫哨塔和月面回响。六关战斗的目标时长为 180–300 秒，剧情另计。

## 运行

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址，默认 `http://127.0.0.1:4173`。游戏运行时没有第三方依赖。开发验收使用 TypeScript 和 Playwright。

## 操作

- WASD 或方向键移动，空格冲刺。
- P 或 Escape 暂停，升级时用鼠标或数字 1、2、3 选择模块。
- 触屏设备使用左侧摇杆与右侧冲刺按钮。
- 右上角切换中英文和声音。
- 开场可跳过。首次赢下当前最远关卡会解锁下一关。结算可重新部署同一关或返回选关，解锁下一关时也可直接进入下一关开场。
- 浏览器本机保存解锁进度。重新部署时重新构筑，刷新会结束进行中的战斗。玩家界面没有回放入口。

## 验证

```sh
npm test
npm run check
npm run verify
```

`test` 覆盖模拟、六关流程、进度存储、内部回放和音频生命周期。内部回放重新执行录制的输入并核对终局校验值，录制仅保留在当前页面内存。`check` 检查代码注释、模拟边界和构建目录所有文件逐文件 gzip 合计不超过 150 KiB。`verify` 还用三个种子完整模拟沙漠基地，检查回放一致且至少存在一个胜局。浏览器试玩步骤见 [verify-lunar](.agents/skills/verify-lunar/SKILL.md)。

GitHub Actions 在 PR 创建、重开和更新时运行浏览器验收。首次本地复跑时，安装 Chromium Headless Shell，然后构建并运行验收。

```sh
npx --no-install playwright-core install --only-shell chromium
npm run build
npm run test:browser
```

脚本用中文桌面键盘和中英文窄屏模拟触控验证移动、冲刺、沙漠胜利报告和雨林解锁恢复。主战斗使用固定种子和自动输入。Linux 缺浏览器系统依赖时，在安装命令中加上 `--with-deps`。

命令的输出和终局结果保存在终端显示的 `.audit/runs/run-*/` 目录。若异常退出遗留 `.audit/dist-transaction`，先按其中的 `owner.json` 确认该命令及其子进程均已退出，再删除事务目录并重试。

打开地址时添加 `?debug`，控制台会输出渲染计数和实体数量。正常日志记录任务开始、状态切换、升级、结算和回放。错误进入控制台并显示页面通知。

## 资源与限制

像素精灵由字符矩阵和共享调色板生成到浏览器内存图集。月壤、陨石坑、基地、太阳能板和地球由 Canvas 指令生成。音乐使用文字音序和 Web Audio 的方波、三角波、正弦波与噪声实时合成，无下载图片、字体或音频。

本机存档仅记录解锁进度，绑定当前站点和浏览器。回放校验对应录制的关卡、规则版本与运行环境。目标手机的性能以真机测量为准。
