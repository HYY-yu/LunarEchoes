# 月面回响 · Lunar Relay

原创月球科技风幸存者原型。固定 3 分钟任务，自动开火，采集能源并选择模块。击败 2 分 20 秒出现的收割者，在 3 分钟时完成信号同步。

## 运行

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址，默认 `http://127.0.0.1:4173`。运行时没有第三方依赖，仅开发工具 TypeScript。

## 操作

- WASD 或方向键移动，空格冲刺。
- P 或 Escape 暂停，升级时用鼠标或数字 1、2、3 选择模块。
- 触屏设备使用左侧摇杆与右侧冲刺按钮。
- 右上角切换中英文和声音。
- 完成一局后选择回放，游戏重新执行逐帧输入，结束后比较校验值。播放中可从右上角返回基地。录制仅保留在当前页面内存，刷新页面会清空。

## 验证

```sh
npm test
npm run check
npm run verify
```

`test` 检查确定性、暂停、升级、死亡、重开、边界输入、角落出生、回放版本和音频异步暂停。`check` 使用 TypeScript 语法树检查代码注释，检查模拟边界，以及构建目录全部文件逐文件 gzip 合计不超过 150 KiB。`verify` 还让三个种子的输入机器人完整试玩，检查回放一致且至少存在一个胜局。这些检查不证明游戏平衡适合所有玩家。

打开地址时添加 `?debug`，控制台会输出渲染计数和实体数量。正常日志记录任务开始、状态切换、升级、结算和回放。错误进入控制台并显示页面通知。

## 资源与限制

像素精灵由字符矩阵和共享调色板生成到浏览器内存图集。月壤、陨石坑、基地、太阳能板和地球由 Canvas 指令生成。音乐使用文字音序和 Web Audio 的方波、三角波、正弦波与噪声实时合成，无下载图片、字体或音频。

首版是 2D Canvas 原型，没有账户、服务端排行榜、持久存档或线上部署。回放只保证当前游戏版本与相同 JavaScript 数学环境，不作为跨引擎防作弊证明。尚未使用 TLA+ 或实现热路径零分配检查。性能需在目标手机上实测，不以作者游戏的指标作为本项目测量结果。
