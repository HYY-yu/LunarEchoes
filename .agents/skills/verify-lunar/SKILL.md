运行 `npm run verify` 并保存真实输出。确认沙漠基地三个种子的完整模拟、至少一个胜局及终局回放校验通过。确认六关相关测试、`test/desert-replay.test.mjs` 的完整录制与异常数据检查、`test/opening-main.test.mjs` 的胜负终局内部回放检查通过。任一脚本失败即停止交付并修复。

运行 `npm run dev` 并打开终端显示的本地地址。从选关或启动任务进入开场，再部署或跳过。使用 WASD 和空格操作，确认自动开火、拾取、升级冻结、模块选取和暂停恢复。切换语言与声音。完成一次终局，检查结算、同关重新部署和返回选关。以窄屏触屏模式检查摇杆和冲刺。检查控制台没有未处理错误。玩家界面没有回放入口。内部回放以自动测试取证。

按 Issue 验收约定覆盖改动影响的关卡、语言、设备与交互。涉及推进时，实测真实胜利后解锁下一关及刷新恢复。涉及视觉时，在实际显示尺寸下对照参考特征并操作受影响的界面。记录每个场景的预期、观察结果和证据。

报告单测结果、gzip 字节数、实际浏览器操作以及尚未实测的设备范围。不能用构建通过代替浏览器验收，不能声称形式化证明或目标手机帧率。
