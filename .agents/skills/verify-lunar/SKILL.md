description: 验证月面回响的模拟、下载预算、代码约束和浏览器完整任务流程。
---

运行 `npm run verify`，保存真实输出。检查三个种子的模拟结果；模拟会将完整录制回放，并断言回放与终局的校验值一致。确认 `test/desert-replay.test.mjs` 的完整录制及异常数据检查和 `test/opening-main.test.mjs` 的胜负终局内部回放检查通过。任一脚本失败即停止交付并修复。

运行 `npm run dev`，打开终端显示的本地地址。点击启动任务，使用 WASD 和空格操作。确认自动开火、拾取、升级冻结、模块选取和暂停恢复。切换语言与声音。完成一次终局并检查结果页面和重新部署。以窄屏触屏模式检查摇杆和冲刺。检查控制台没有未处理错误。当前界面没有回放入口；内部回放由上述自动测试覆盖，不能将其报告为浏览器实测。

报告单测结果、gzip 字节数、实际浏览器操作以及尚未实测的设备范围。不能用构建通过代替浏览器验收，不能声称形式化证明或目标手机帧率。
