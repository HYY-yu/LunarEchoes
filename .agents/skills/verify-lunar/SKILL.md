## 选择验收范围

- 独立模型和场景方案以实际游戏镜头和显示尺寸下的预览验收。涉及动画时查看动态预览。
- 仅修改文档、工作台或定时配置时，直接检查改动结果。例如修改收发入口后，从两个 worktree 验证投递与读取。
- 游戏代码 PR 合并前，确认 CI 的 `npm run verify` 在当前提交上通过。自动验证覆盖六关测试、下载预算、沙漠基地三个种子的完整模拟及终局回放校验。检查失败时，先定位并修复，再复核。
- 涉及玩家可见的呈现或交互时，试玩改动影响的流程。按任务验收约定覆盖受影响的关卡、语言和输入方式。

## 试玩受影响的流程

运行 `npm run dev` 并打开终端显示的地址。按任务的完成标准复现改动，检查控制台并记录预期、实际结果和证据。整合视觉改动时，在实际显示尺寸下检查游戏内呈现。

改动胜负条件、关卡推进、存档或影响整局的战斗流程时，跑完受影响关卡的开场、战斗、结算、重新部署和返回选关。涉及解锁或存档时，实测达成胜利后的解锁和刷新恢复。涉及移动输入时，覆盖键盘移动和冲刺，以及窄屏触控摇杆和冲刺。内部回放使用自动测试验证。

报告实际执行的检查、结果和未覆盖的相关设备范围。用 CI 结果记录自动验证和 gzip 体积，用实际操作结果记录试玩。
