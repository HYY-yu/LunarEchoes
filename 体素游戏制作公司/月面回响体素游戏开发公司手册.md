
## 组织原则

不断完善和推进月面回响游戏进度，让它成为一款受人欢迎的好游戏，一款靠打怪成长\修复基地通关的幸存者塔防游戏。

## 公司制度

### OKR 制度
[[数据/契约条目/目标与关键结果|目标与关键结果]]

- 目标：游戏场景升级，体素堆叠技术升级
- 关键结果：
	- 体素堆叠技术带来的 3D 场景升级，保持第三人称俯视视角，但将带来空间感
	- 现有的游戏角色、怪兽角色升级为体素 3D 模型，纯代码绘制
	- 不影响现有玩法，保持自动射击、收集宝石升级

- 目标：类似我的世界的物品合成体系，以基础的木头+铁矿为基础，合成箭塔，以特殊道具为辅，可升级成火箭塔、电箭塔、炮弹塔。
- 关键结果： 
	- 构造背包，专门用于收集木头、铁矿，限制玩家一次能拿的最大数量
	- 箭塔可以使用木头、铁矿持续升级，特殊箭塔也走相同的升级道路，只是子弹有特殊效果
	- 塔的射角为 120 °
	- 塔修好后马上就可以投入战斗
	- 火箭塔：持续火伤，但射速低 （相比基础箭塔）
	- 电箭塔：盾牌穿透，射速快，但伤害稍低（相比基础箭塔）
	- 炮塔：范围伤害，箭变成炮弹，但升级需要更多的铁和木头 （相比基础箭塔）

- 目标：地图场景优化升级
- 关键结果：
	- 每关地图增加残破炮塔位，围绕主基地的东南西北四角
	- 玩家前半局自己扛住敌潮，后半局亲眼看到修好的基地接手防御。
	- 地图增加木材资源、铁矿资源
	- 地图增加特殊道具反馈，每张图都带有隐藏宝箱，埋藏在地图随机位置，玩家经过将收到无线电提示，玩家仔细探索附近区域如果踩中宝箱，则自动显示宝箱并自动打开，弹窗告知玩家特殊道具（可以改造炮塔）：火种、电磁电池、火药

- 目标：怪物升级
- 关键结果：
	- 每关新增特色 boss，设计每关不同的 boss ，相貌样式均不同
	- 每关 boss 设计特色技能：召唤小崽、弹雨冲击、铠甲防御、呼叫空袭、幻影分身、时间暂停
	- 原先的怪兽保留，新增几种新的基础怪兽：冰霜盾牌兵（克火箭塔）、绝缘服小兵（克电箭塔）、火箭炮机器人（克炮塔）

- 目标：游戏流程优化
- 关键结果
	- 游戏胜利条件，由坚持 3-5 分钟，改为修复四座炮塔后，扛住最后一波大敌潮
	- 每关线性持续产生敌潮，当玩家完成一个炮塔修复，产生一波小敌潮，每关相同
	- 敌潮生成公式需要让玩家游玩时间大致控制在 5 分钟左右
	- 利用无线电引导玩家的下一步行动，比如：收集素材恢复炮塔，持续升级炮塔，扛住最后一波敌潮等。

（注意：每位员工，如果没有填写自己的目标与关键结果，请务必填写，按以上 OKR 拆解自己的工作）

### 日报制度

每个角色提交[[数据/契约条目/日报|日报]]，由老板逐份查看并在需要时批复。每份日报包含以下五部分。

1. **当日已完成工作**。选 1–3 项关键成果，用简化 STAR 说明背景与任务、采取的行动、结果。尽量附 Issue、PR、文档、预览或测试结果等可追溯证据。
2. **明日计划工作**。概述计划事项、预期交付物和完成标准，必要时附老板可访问的 PR 或证据链接。跨天任务补充当前里程碑和预计完成日期，每日更新实际变化。
3. **需要的协助**。逐项写明卡在哪里，以及未解决会影响哪个交付。需要老板介入时，概述卡点和影响，并附适合分享的证据。
4. **OKR 进度**。执行者逐条关联 KR，写明基线、当前值、目标值、相对上次的变化和风险，并尽量附可复核证据。审核者在日报汇报自身复核进展及需要协助的事项。
5. **领导批复**。由老板按需填写决定、反馈或下一步要求，保留在原日报上。

### 工作项与 Agent 间沟通

Agent 之间通过角色[[角色发件箱]]和[[角色收件箱]]沟通。发送者在自己的发件箱记消息和期望动作，再投递到对方收件箱。接收者处理后，如需回复，在自己的发件箱引用原消息并投递回去。审核者只与绑定的执行者沟通。

## 空闲与退出

逐项检查当前是否有可推进的事。全部无可行动事项时，角色可以主动结束本轮智能循环。等待回复、尚未到期且当前无动作的事项可在下一轮继续跟踪，并保留原状态。

- 执行者检查 OKR、PR、收件箱、发件箱和日报。这五处都没有可推进的事项时，可以退出本轮循环。
- 审核者检查收件箱、发件箱和日报跟踪。这三处都没有可推进的事项时，可以退出本轮循环。日报跟踪限于和绑定执行者的审核相关的事项。
