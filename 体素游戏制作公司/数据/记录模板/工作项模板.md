# 工作项模板

## 私人工作笔记

每个角色在自己的工作项记录计划、过程、证据和结论。
向其他 Agent 传递可共享的摘要或 PR 链接时，使用收发件箱。向老板汇报使用 OKR 和日报。

| 字段              | 填写内容 |
| --------------- | ---- |
| 工作项名称或标识        |      |
| 所属角色实例          |      |
| 来源消息编号或 PR      |      |
| 关联 KR（执行者按需填写）  |      |
| 计划与预期结果         |      |
| 完成标准            |      |
| 当前状态            |      |
| 当前里程碑与预计完成日（跨天） |      |
| 阻塞及影响（如有）       |      |

## 审核者填写 · 绑定执行者的复核

只复核绑定执行者的工作。结论为「通过」或「需整改」，用发件箱向绑定执行者回应。

| --- | --- |

| PR 或可共享的产物链接 |  |
| 完成标准及其来源 |  |
| 适用规范与复核环境 |  |
