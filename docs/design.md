# 月面回响设计

## 体验

灰白月壤、青色中继能源、琥珀敌弹构成月球科技风。主画面始终是月面场景。菜单覆盖场景，升级时冻结战斗。

任务持续 180 秒。玩家用走位和冲刺躲避机械敌群，武器自动攻击最近敌人。敌人掉落能源，升级时选择三个模块之一。基础脉冲步枪、环绕无人机、范围电磁新星形成不同攻击方式。推进器、装甲与采集器补充生存选择。140 秒出现收割者，击败它并坚持到 180 秒获胜。

## 模块与边界

| 模块 | 责任 |
|---|---|
| `src/core.ts` | World、固定步长模拟、显式 Action、状态机、种子随机数、回放与 checksum |
| `src/main.ts` | 输入、录制与回放播放、浏览器生命周期、DOM 菜单与 HUD |
| `src/render.ts` | 只读 World、程序月面场景、镜头与视觉反馈 |
| `src/art.ts` | 共享调色板、字符像素精灵、内存图集 |
| `src/audio.ts` | 文字音序、多声部合成器、事件音效 |
| `src/i18n.ts` | 中文与英文界面和模块文案 |
| `src/logger.ts` | 结构化日志与 debug 开关 |

`dispatch(world, action)` 是模拟写入口。`createWorld(seed)` 创建全新世界。`replay(recording)` 从种子重新执行命令。渲染和音频不反向改变模拟。核心不读取浏览器时间、DOM、音频或系统随机数。

Phase 是 running、upgrading、paused、won、lost 的联合类型。只有 running 处理 tick。升级只能选择当前 offers 中的一个模块，然后回到 running。终局不再推进。

## 记录与复现

Recording 包含 version、seed 和有序 actions。每个 tick 的方向与冲刺输入被记录，升级、暂停和恢复也记录。回放不包含音频或视觉时间。checksum 对模拟状态计算哈希，忽略瞬时音频事件。

版本变更可能改变随机调用顺序、伤害或实体顺序，因此拒绝不同 version 的回放。相同版本的确定性测试属于运行证据，没有进行跨浏览器浮点一致性证明。未来服务端验分应复用同版模拟并验证输入数量、序列和资源上限。

## 工程选择

pstack 设计探索比较了可变固定步长 World 与不可变 reducer 快照。采用前者，减少实体更新时的对象复制；吸收后者的显式命令和事件。Canvas2D 使首版没有大型运行时依赖。原型仍有数组过滤和临时分配，不宣称零 GC。

图集在浏览器启动时生成，没有构建期位图工具链。下载预算覆盖 dist 所有文件逐文件压缩后的合计值，比仅统计首屏模块更保守，但不包含 HTTP 头。

## 验证与后续

先验证可重放的完整一局，再加入更多内容。行为单测覆盖状态转移，无头机器人覆盖真实输入驱动与回放一致。Chrome 已检查启动画面、键盘移动与冲刺、升级选择、语言切换、暂停冻结、死亡结算，以及一次真实试玩的回放校验一致。390px 窄屏未发生横向溢出，触屏模拟已检查摇杆拖动和松手复位。目标手机性能、真机多点触控、音频听感与人工平衡反馈仍需实测。
