# 雨林战场预览

雨林研究站外的三处战场是林冠阴影、遗迹空地和盘根通路。切换区域可对照同一段交战动画，检查工程兵和敌人在不同地表上的轮廓，以及弹幕与攻击预警是否清楚。地形只供渲染评审。

```sh
npm ci
npm run build
node scripts/rainforest-battle-audition.mjs
```

打开 [本机战场预览](http://127.0.0.1:4190/)。区域按钮将动画重置到警告阶段，暂停可固定当前画面，语言按钮可切换中英文。启用减少动态效果的浏览器默认暂停，可手动继续。

三处复用游戏现有像素图集和同一组工程兵、爬行敌、哨兵。角色和预警绘制在地形上层。浅青小弹和橙色方弹用颜色及尺寸区分，警告以金色虚线环和深色描边标识。画布按显示区取景，窄屏保持战斗对象的显示尺寸。运行时继续使用现有沙漠地图，预览入口由本机单独提供。

对照 [Returnal 官方实机](https://blog.playstation.com/2021/04/29/returnal-gameplay-dev-details-and-more-in-nearly-30-minutes-of-new-footage/)，取其暗林遗迹中将明亮弹道与地面细节分离的做法。地形和动画由项目代码生成，角色来自现有图集。

## 浏览器验收

在桌面 1280×720 和窄屏 390×600 打开预览。逐个切换三处，暂停检查角色、两种弹幕和金色虚线，再继续观察角色移动、弹道移动与预警消退。切换中英文，确认区域名称与图例完整，按钮可操作，页面没有横向滚动或控制台错误。窄屏可用 Chrome 触屏仿真操作区域和暂停按钮。
