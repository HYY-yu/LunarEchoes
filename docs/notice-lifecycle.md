# 通知生命周期

Boss 提示与错误共用一个本地通知节点。新通知替换旧通知，保留 3500 ms，然后清空文本、visible class 和 timer 句柄。

成功部署、Retry、Replay 和返回主页清理上一会话通知。清理发生在世界创建或回放准备成功之后，在 UI 刷新和音频启动之前。准备失败仍显示原有双语错误，保留原日志级别与完整时长。

暂停、失焦、页面隐藏、语言和声音切换不代表退出会话，不提前清理通知。已经发布的文字保持原语言，下一条通知使用当前语言。

运行 `npm run verify`。`test/opening-main.test.mjs` 执行实际 main，用独立于 RAF 的测试计时器验证 3499/3500 ms、替换、取消和会话边界。故障输入和状态观察只存在于 VM 测试，不进入产品。

真实浏览器须以正常随机种子、输入和时间到达 140 秒 Boss，分别观察提示出现及到期后的空 DOM status。终局通常在通知到期后，终局按钮操作不能证明显示中的 timer 取消。此取消由 VM 测试验证。测试和离线模拟不证明实体触屏、FPS 或听感。
